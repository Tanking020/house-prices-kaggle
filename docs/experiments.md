# 实验记录

> **纪律**：每次改动都要记录 —— **改了什么 → CV 分数 → 结论**。
>
> 不记录 = 学不到东西，也无法判断"改动到底有没有用"。
> 这份表同时也是**简历里"证据链"的素材来源**。

---

## 记录规则

1. **一次只改一个变量** —— 否则不知道是哪个改动起的作用
2. **用同一套 CV 划分对比** —— 固定随机种子，否则差异可能只是随机抖动
3. 记录 **CV 分数**；数据量小时建议记「重复 CV 的均值 ± 标准差」
4. 写清楚**结论** —— 这个改动是**留下**了还是**回退**了
5. **失败也要记** —— 负结果同样是知识，避免重复踩坑
